# Phase plans and lab notes

Two kinds of files are in this directory:

- **Pre-registered plans** (`PHASE<n>_<topic>.md`, `SUPPLEMENT<n>_<topic>.md`). Each was written before its phase was run. It contains the hypotheses, the procedure and the decision gate.
- **Running notes** (`PHASE<n>_REPORT.md`, `SUPPLEMENT3_REPORT.md`, `SUPPLEMENT6_DECISION_NOTE.md`, `NEXT_STEPS_NEURAL_GEOMETRY_NO_TRAINING.md`). These were written while the experiments were run. They are lab notebooks, kept largely as recorded, so their wording is informal and some conclusions were revised later.

The formal write-ups are the PDFs in `reports/`. Corrections to both the notes and the reports are listed in `docs/ERRATA.md`. Where a note repeats a count that was later found to be wrong, it is marked `[see ERRATA E<n>]`.
